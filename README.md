# 《My Superhot》 | 非线性时间流速 FPS 游戏 Demo

> 基于 Unity 开发的极简风格第一人称射击游戏 Demo，作为本人《游戏设计与开发》课程的结课作业。

本项目 Demo 核心机制复刻了《SUPERHOT》的“时空联动”玩法：玩家移动或开火时时间恢复正常，仅转动视角时时间近乎冻结。剧情讲述主角在几何密室中突围，仅为关卡包装；项目重点在于展示底层时间系统、武器交互、敌人行为 AI 与视听反馈的完整实现。

## ✨ 核心特性

- **1. 非线性时间流速系统**：无需手动按键，系统根据“移动/攻击/仅转视角”自动平滑调节全局时间流速（最快常速，最慢降至 3%）。
- **2. 实体子弹与冷热兵器**：采用实体子弹（非射线检测）在慢速下编织可视弹道网；支持手枪射击、武士刀扇形近战、武器投掷/反弹/二次拾取。
- **3. 玻璃破碎与布娃娃系统**：敌人采用红外玻璃材质，受击部位隐藏网格、实例化碎片并施加爆炸力，配合布娃娃系统呈现碎裂效果。
- **4. 双轨异构敌人 AI**：近战兵使用真实时间戳防“抽风”，远程兵引入时轴反拉补偿防“死寂”，保证慢速下弹幕压迫感；且敌人波次刷新机制与工程时间规矩动态关联，检测敌人单位并实时补充。
- **5. 动态死亡回放（Killcam）**：克隆相机进行影视级轨道环绕运镜，同时压低音频低通滤波至 900Hz，呈现电影级击杀特写后瞬间恢复。

## 🎮 操作指南

| 按键 | 功能 |
|---|---|
| `W / A / S / D` | 移动（触发时间流速恢复） |
| `鼠标移动` | 旋转视角（仅转视角时进入子弹时间） |
| `鼠标左键` | 开火 / 挥砍 |
| `鼠标右键` | 投掷当前武器 |
| `E` | 交互（拾取武器 / 触发传送门 / 彩蛋互动） |
| `空格键` | 跳跃 |
| `R` | 重启当前关卡 |
| `C` | 开关玩家无敌（调试后门） |
| `ESC` | 暂停游戏 |

> **时间控制说明**：无需手动操作，遵循工程时间线，通过检测玩家行为自动触发。

## 🛠️ 运行环境与构建

- **引擎**：Unity 2022.3 LTS (2022.3.62f3)
- **核心依赖**：DOTween、TextMeshPro
- **渲染管线**：内置管线（Built-in Render Pipeline）

**如何运行源码**：
1. 安装 Unity Hub 与 Unity 2022.3.62f3 版本。
2. 在 Unity Hub 中点击“打开项目”，选择仓库根目录。
3. 等待编译完成后，打开主场景，点击 **Play** 即可运行。
4. 如需打包：`File → Build Settings → Windows → Build`。

>  **存在配置 Unity 问题？** 可从 [Releases](https://github.com/Trh-5631/My-Superhot/releases) 下载打包好的版本解压游玩（ Windows 版本）。
